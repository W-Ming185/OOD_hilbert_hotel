# Distributed Hilbert's Hotel (Consistent Hashing)
Python 3.13 (tested). Standard library only, except the experiment needs matplotlib (pip install matplotlib).

Run everything from the project root folder (the folder containing this README):
- python -m Module.HotelCLI                 -> menu program
- python -m experiment.experiment           -> experiments, CSVs and graphs (saved in result/)
- python -m unittest Module.test_hotel -v   -> automatic tests
